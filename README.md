# STM32F407 + C620 电机速度环控制

## 1. 系统总览

```
┌─────────────────────────────────────────────────────────────────┐
│                         STM32F407                              │
│                                                                 │
│   TIM8 (1kHz)          PID.c              CAN1 (1Mbps)          │
│   ┌──────────┐     ┌─────────────┐     ┌──────────────┐        │
│   │ 每 1ms   │────▶│ 速度环 PID   │────▶│ 发送电流指令  │────────│──▶ C620 电调
│   │ 触发中断 │     │ VEL_KP=2.0  │     │ CAN ID:0x201 │        │
│   │          │     │ VEL_KI=0.05 │     │ 8字节大端    │        │
│   └──────────┘     │ VEL_KD=0.0  │     └──────────────┘        │
│                    │             │                              │
│                    │ 目标:1000RPM│     ┌──────────────┐        │
│                    └─────────────┘     │ 接收反馈帧   │◀───────│── C620 电调
│                                        │ CAN ID:0x201 │        │
│                                        │ 转速/角度/温 │        │
│                                        └──────────────┘        │
└─────────────────────────────────────────────────────────────────┘
```

**一句话总结**：TIM8 每 1ms 触发一次中断 → 读 C620 电机反馈转速 → PID 计算电流指令 → CAN 发给电调 → 电机按目标 1000RPM 转。

## 3. 数据流详解

### 3.1 反馈接收（CAN → 电机状态）

```
     C620 电调                          STM32
    ┌──────────┐                    ┌─────────────────────────┐
    │ 每 1ms   │                    │ CAN1 RX FIFO0           │
    │ 自动发送 │── CAN ID 0x201 ──▶│ 触发中断                 │
    │ 反馈帧   │    8 字节           │                         │
    └──────────┘                    │ HAL_CAN_RxFifo0Msg     │
                                    │ PendingCallback()     │ Can.c:82
                                    │   ↓                    │
                                    │ 解析 8 字节：           │
                                    │   Byte0-1 → angle      │
                                    │   Byte2-3 → speed      │
                                    │   Byte4-5 → current    │
                                    │   Byte6   → temp       │
                                    │   ↓                    │
                                    │ C620_UpdateFeedback()  │ PID.c:48
                                    │   存入 g_feedback       │
                                    └─────────────────────────┘
```

**C620 反馈帧格式**（CAN ID = 0x201~0x208，对应电机 1~8）：

| 字节 | 含义 | 类型 | 说明 |
|------|------|------|------|
| Byte0-1 | 角度 | uint16 大端 | 0~16383 (14bit 编码器) |
| Byte2-3 | 转速 | int16 大端 | 单位 RPM |
| Byte4-5 | 电流 | int16 大端 | 实际电流 |
| Byte6 | 温度 | uint8 | 单位 ℃ |
| Byte7 | 保留 | — | — |

### 3.2 指令发送（PID 输出 → CAN）

```
    PID.c: C620_CAN_1kHz_Task()
    ┌──────────────────────────────────────┐
    │                                      │
    │  error = 1000 - g_feedback.speed     │  计算转速误差
    │    ↓                                 │
    │  积分分离（见 4.2）                   │
    │    ↓                                 │
    │  output = Kp*e + Ki*∫e + Kd*de/dt   │  PID 公式
    │    ↓                                 │
    │  输出限幅 ±16384 + 抗积分饱和         │
    │    ↓                                 │
    │  PackCommand(tx, output, id=1)       │  打包成大端 int16
    │    ↓                                 │
    │  C620_CAN_SendMessage(...) ──────────│──▶ CAN1 TX → C620 电调
    │                                      │
    └──────────────────────────────────────┘
```

**C620 指令帧格式**（CAN ID = 0x200 + motor_id）：

| 字节 | 含义 | 说明 |
|------|------|------|
| Byte0-1 | 电机1电流 | int16 大端，范围 -16384~16384 |
| Byte2-3 | 电机2电流 | 同上 |
| Byte4-5 | 电机3电流 | 同上 |
| Byte6-7 | 电机4电流 | 同上 |

> 当前只用了电机1（`C620_MOTOR_ID_1 = 1`），所以只有 Byte0-1 有值，其余为 0。

## 4. 速度环 PID 详解

### 4.1 参数表

| 宏 | 值 | 含义 |
|----|-----|------|
| `VEL_KP` | 2.0 | 比例增益 — 误差越大，输出越大（瞬时响应） |
| `VEL_KI` | 0.05 | 积分增益 — 累积历史误差（消除静差） |
| `VEL_KD` | 0.0 | 微分增益 — 当前未使用 |
| `VEL_TARGET` | 1000 | 目标转速 RPM |
| `OUTPUT_MAX` | 16384 | 输出限幅（C620 最大电流值） |

### 4.2 积分分离策略

```
if (|error| > 200 RPM)    →  integral += error        // 大误差：全量积分，快速逼近
else                       →  integral += 0.2 × error   // 小误差：弱积分，防过冲
```

**设计思路**：
- 启动时转速=0，误差=1000，全速累积积分 → 快速追赶目标
- 快接近时，积分力度降到 1/5 → 平稳到位，不会冲过头

### 4.3 抗积分饱和（Anti-windup）

```c
if (output > 16384) {
    integral -= (output - 16384) / VEL_KI;   // 正饱和：削减积分
    output = 16384;
}
else if (output < -16384) {
    integral -= (output + 16384) / VEL_KI;   // 负饱和：削减积分
    output = -16384;
}
```

当 PID 输出超出 C620 电流范围时，自动削减积分项，防止积分"膨胀"导致控制滞后。

### 4.4 三段式工作流程

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  [阶段1] 0~500ms 启动延时                                        │
│    发送空电流指令（tx[8] = {0}），让电调完成自检初始化             │
│                                                                  │
│  [阶段2] 500ms 之后                                              │
│    正常 PID 控制，每 1ms 执行一次                                 │
│                                                                  │
│  [阶段3] 稳态                                                    │
│    积分持续累积，消除静差，维持 1000 RPM                          │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 5. 时序与中断链

```
TIM8 时钟 = 168MHz（APB2×2，因为 APB2 分频器≠1）
  │
  ├─ Prescaler=167 → 计数频率 168M/168 = 1MHz = 每 1μs 计数一次
  │
  ├─ Period=999 → 每 1μs×1000 = 1ms 溢出一次 → 1kHz ✅
  │
  └─ 回调链：
       TIM8 CH3 比较匹配(CCR=999)
         → HAL_TIM_IRQHandler()
           → HAL_TIM_OC_DelayElapsedCallback()    [main.c:422]
             → HAL_GPIO_TogglePin(PH12)           LED 翻转（示波器可看）
             → C620_CAN_1kHz_Task()               [PID.c:62]
```

> STM32F4 定时器时钟规则：APB 分频器=1 时，定时器时钟=APB 时钟；分频器≠1 时，定时器时钟=2×APB 时钟。
> 此处 APB2=84MHz(DIV2≠1)，所以 TIM8 时钟=168MHz，代码正确。

## 7. 调参指南

### 如果电机响应太慢（转速上不去）
→ 增大 `VEL_KP`（例：2.0 → 5.0）

### 如果电机震荡（转速来回摆动）
→ 减小 `VEL_KP` 或 `VEL_KI`

### 如果稳态有静差（停在 980RPM 不到 1000）
→ 增大 `VEL_KI`（例：0.05 → 0.1）

### 如果启动时过冲严重
→ 调小积分分离阈值 200 或降低小误差时的积分系数 0.2

### 如何看波形
- GPIO PH12 每 1 个控制周期翻转一次 → 接示波器验证控制频率
- 用 CAN 分析仪抓 0x201 帧看 C620 真实转速和电流

## 8. C620 初始化流程

```
main()
  │
  ├── HAL_Init()                    系统初始化
  ├── SystemClock_Config()          时钟 168MHz
  ├── MX_GPIO_Init()                GPIO
  ├── MX_CAN1_Init()                CAN1 波特率 1Mbps
  ├── MX_TIM1_Init()                TIM1 PWM（预留）
  ├── MX_TIM8_Init()                TIM8 500Hz 定时中断
  │
  ├── C620_Init()                   ★ 一步搞定：
  │     ├── 保存 CAN 句柄
  │     ├── 配置滤波器（接收所有帧）
  │     ├── HAL_CAN_Start()
  │     ├── 使能 RX FIFO0 中断
  │     ├── 清零反馈数据
  │     └── 记录启动时刻
  │
  ├── HAL_TIM_OC_Start_IT()        启动 TIM8 中断
  │
  └── while(1) {}                  主循环空闲，一切在中断里跑
```
